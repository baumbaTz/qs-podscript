Get started

{{with .User}}Welcome, {{.Name}}! {{end}}There are two ways to help with {{.Data.Origin}}. You can do either, or both.

A. In your browser – nothing to install

{{if .User}}

Open a podcast you were given access to and fix what the computer got wrong: click a word to correct it or say who spoke, double-click a word to play from there, click a speaker's name to fix a whole paragraph. The manual explains it step by step.

{{else}}

Log in (top right) and open a podcast you were given access to. Click a word to correct it or say who spoke. No account yet? Ask the people running this site for an invite link.

{{end}}

B. Lend your computer – it transcribes episodes for this server

Turning an episode into text takes a lot of computing power, so the work is done by volunteers' computers (a graphics card makes it much faster). Everything stays in your own copy of QS-PodScript; it only fetches an episode, transcribes it and sends the result back. Four steps:

2. Install

  • Windows: unzip the file and double-click install.cmd. It downloads everything needed (about 2.5 GB, once). No administrator rights needed.
  • Linux: in a terminal: tar xzf qs-podscript-*-linux-x64.tar.gz, then cd qs-podscript-* and ./install.sh.
  • macOS: install the tools once with Homebrew – brew install ffmpeg whisper-cpp – then double-click QS-PodScript.command in the unzipped folder (the README inside explains how to allow the unsigned app).

The installer asks once whether to connect to a shared server – you can already do step 3 there. Answer with {{.Data.Origin}}, your name{{with .User}} ({{.Name}}){{end}} and your password.

3. Connect it to this server

Start QS-PodScript. A window opens and your browser shows it at http://127.0.0.1:8321/ – that is your copy, not this site. There open Setup → Where you work → Add a server and enter:

  • Server address: {{.Data.Origin}}
  • Your name: {{with .User}}{{.Name}}{{else}}the one you chose when you joined{{end}} – and your password. The password is used once; your computer gets its own key, which an admin or you can revoke.

4. Start helping

In Setup switch on Transcribe for this server, then press Start transcribing (top right). Your computer takes one episode at a time and keeps going until you press Stop. Keep the QS-PodScript window open while it works; nothing starts by itself.

Stuck? The manual has a chapter When something goes wrong; the people running this site can help too.
